## 4. 세 영역 UI (§5) (`59b4d71`)
- **경계 규칙(배타적) = 시점(Due/Resurface) 유무가 최상위 축**: 시점 있음→"지금 챙길 것"(확정 무관, 완료 시 보관) / 시점 없음+미확정→"새 기억들"(오래된 순·임시 배지·왼쪽 스와이프 확정) / 시점 없음+확정→"살아있는 기억"(필터 여기로). 이유: 시점=현실 사건은 보관 흐름, 살아있는 기억은 시점 없는 것(아이디어·지식)의 몫(to-do 오염 방지).
- 탭: 새로운 기억·검색·**살아있는 기억**(가운데)·보관된 기억·설정. 원칙/수집 탭 제거, `PrincipleView.swift` 삭제(원칙=상단 ambient 띠).
- 대시보드 5숫자: **원칙**·챙길 것·미확정·확정·총 기억. (원칙 타일은 실기기 검증 후 추가.)
