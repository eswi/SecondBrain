- **설계 문서 정본**: `docs/native/audio-capture-design.md` (질문 6개 + 여러 take 한 파일 + iCloud 헤드룸).

  Core 접촉은 `EventWriter` 화이트리스트 **1줄**(`"audio"`)뿐. **MergeEngine·EventLog·merge-design 무변경.**

## 2. 구현(파일별)
- **새 `AudioStore.swift`** — 음성 디렉터리(앱 샌드박스, 기본 기기전용)·임시 생성·확정(이동, write-once)·id 조회(위치 추상화). 위치 탐색을 배열로 두어 **나중 iCloud 위치 추가만으로 항목별 동기화** 가능(§7 헤드룸).
- **`EventWriter`(Core)** — create 블록 화이트리스트에 `"audio"`. 코어 테스트에 왕복 케이스 추가 → **65/65**.
- **`SpeechCapture.swift`** — 세션 수명 `AVAudioFile` 하나. 조각회전(tap 재설치)·[정지]→[재개](엔진 재시작)를 다 넘어
  **같은 파일에 이어 쓰기**. 정지=일시정지(파일 유지)/[저장]·[취소]에서만 닫음. `finishAndURL()`/`cancelAndDiscard()` 추가.
  1차=직접 쓰기(포맷 고정). AVAudioConverter는 불필요·동시성 경고로 제거.
- **`InboxModel.capture(audioTemp:)`** — 저장 시 UUID로 음성 확정(`<uuid>.m4a`) + `audio:` 성역 포인터. 텍스트 없으면 임시 삭제.
- **`CaptureSheet.swift`** — [저장] 시 음성 확정 전달 / 미저장 종료 시 `cancelAndDiscard`(임시 삭제). `saved` 플래그로 이중 정리 방지.
- **새 `AudioPlayer.swift` + `DetailView`** — 성역 카드에 "원본 음성 다시 듣기"(있으면 재생, 없으면 "이 기기엔 없음").
