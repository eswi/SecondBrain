# 작업 로그 — 2026-07-16 (SecondBrain)

> Mac mini 네이티브 개발환경 세팅·검증. 코드 변경 없음(환경 준비만). 다음 개발은 **MacBook Pro에서 재개** 예정.

## 0. 세션 목적
- MacBook Pro에서 push한 네이티브 v1 Phase 1 작업을 **Mac mini에서도 빌드·구동 가능하게** 환경 준비.
- 실제 개발은 이 세션에서 **하지 않음** — 세팅만 하고 멈춤(사용자 결정).

## 1. 환경 세팅 (A단계) — 결과
- **Xcode 26.2** (Build 17C52) — 이미 설치돼 있음(권장 26.x 충족).
- **Homebrew 6.0.11** — 이미 설치·PATH 등록됨.
- **XcodeGen 2.45.4** — 이번에 `brew install xcodegen`으로 신규 설치.
- **Swift 6.2.3** — Xcode 동봉.
- `git pull` — 로컬이 뒤처져 있어 동기화(`cfd64b1 → bc8d547`). 이때 `native/` 디렉터리·`automation/`·설계문서 등 22개 파일이 처음 내려옴.

## 2. 워크플로 검증 (B단계) — 통과
- `cd native && xcodegen generate` → `SecondBrain.xcodeproj` 생성 성공. (`.xcodeproj`는 gitignore 생성물 — 매번 재생성 필요, 두 Mac 머지충돌 방지 방식.)
- **시뮬레이터 빌드**: `xcodebuild -scheme SecondBrainApp-iOS -destination 'platform=iOS Simulator,name=iPhone 17' build` → **BUILD SUCCEEDED** (서명 불필요).
- **코어 테스트**: `SecondBrainCore/`에서 `swift test` → **FragmentParserTests 3개 전부 통과**.

## 3. 상태
- git: `main == origin/main`, **working tree clean** — Mac mini에서 커밋 안 된 변경 없음.
- 이 세션이 남긴 유일한 repo 변경 = **이 worklog 파일**.

## 4. 다음 개발 재개 시 (MacBook Pro 기준)
- 시작 순서 고정: `git pull` → `cd native && xcodegen generate` → 빌드/Run. (이 worklog까지 pull하면 최신.)
- **미결 결정 (Phase 2 착수 전 필수)**: 설계서 §6 미결 #2 **"수정 이벤트의 v1 범위 — 단순형 vs 완전형"**. 합치기 엔진 설계를 좌우함. 이 세션에선 결정 보류.
- 참고 문서: `native-v1-design-draft.md`, `second-brain-v0-spec.md`.

## 5. 주의 (인수인계)
- `classify.py` / launchd(웹 v0 분류기)는 **네이티브 개발과 무관** → Mac mini엔 설치 안 함(불필요).
- 실기기 iPhone 테스트만 서명 필요(Xcode Signing → Team = 본인 Apple ID, 무료 계정 7일마다 재설치). 지금 개발은 시뮬레이터로 충분.
- iCloud 실데이터 없이도 빌드·구동됨 — Phase 1 앱은 번들 샘플(`inbox-sample.md`) 사용.
