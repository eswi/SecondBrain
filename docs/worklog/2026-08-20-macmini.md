## 3. ★ 실측이 드러낸 것 — **문제는 15초가 아니라 1초 폴링이다**

`MediaFetch.swift:39-45`가 **1초 간격으로** 상태를 다시 본다:

```swift
private static let waitSeconds = 15
...
for _ in 0..<Self.waitSeconds {
    try? await Task.sleep(for: .seconds(1))   // ← 여기
```

| | |
|---|---|
| 실제 다운로드 | **0.53~0.92초** |
| 화면이 아는 시점 | **1.0초**(첫 폴링) — 빠르면 **0.5초를 그냥 기다린다** |
| 15초가 걸리는 경우 | 이 회선에서는 **없었다**(최대 0.92초 = 한도의 **6%**) |

**즉 `waitSeconds`는 넉넉해서 문제가 아니고, 사용자가 느끼는 지연은 폴링 간격이 만든다.**

## 4. ⚠️ 문서의 전제 하나가 흔들렸다 — 「Mac에서 걸린다」

설계 §2-A·§4·HANDOFF가 **「폰은 로컬 사본이 있어 안 걸리고 Mac에서 걸린다」**로 적고 있다.
그런데 **잰 것:** `native/project.yml`에 **엔타이틀먼트 파일이 아예 없다**(`*.entitlements` 0개 ·
`sandbox` 키 0개). 설계 §2도 같은 사실을 *"맥 앱은 App Sandbox entitlement가 없어 보안 스코프가
애초에 안 걸린다"* 로 이미 적어 뒀다.

| | 잰 것 / 추정 |
|---|---|
| 엔타이틀먼트 파일 없음 | ✅ **잰 값** |
| 그래서 **macOS에서 스코프가 no-op**이라 스코프 밖 읽기가 **된다** | ⚠️ **추정.** 문서에 근거는 있지만 **이 앱으로 확인 안 했다** |
| **iOS는 무조건 샌드박스**라 스코프가 **실제로 걸린다** | ⚠️ **추정.** 폰은 로컬 사본이 가려서 **현상이 안 난다** |

> ### ⛔ 그러면 방향이 뒤집힌다
> 「Mac에서 터지고 폰은 안전」이 아니라 **「Mac에서는 안 터지고, 폰에서는 로컬 사본이 가리고 있을 뿐」**일 수 있다.
> 후자면 이건 **잠복 결함**이다 — 폰의 로컬 사본이 없어지는 날(재설치 · 두 번째 기기) **조용히 나타난다.**
> **어느 쪽이든 스코프 수명은 정해야 한다.** 다만 **「Mac에서 재현해서 고친다」는 계획은 성립하지 않을 수 있다.**

## 5. 사용자 결정 둘 (2026-08-20 · 실측을 보고)

| | 답 | 사용자 근거 |
|---|---|---|
| **보안 스코프 수명** | **C — 받으면 로컬에도 둔다** | **★ 「추정 위에 설계를 안 얹는다」가 결정적.** 전제가 흔들린 지금 A·B는 어느 쪽이 맞는지에 따라 설계가 달라지는데 **C만 그 답과 무관하다** — 스코프 밖에서 읽는 코드가 아예 없어진다. 그리고 **「받는 중」이 파일당 한 번으로 끝나는 것은 정직함의 문제** — A·B는 evict될 때마다 다시 받고 사용자는 「아까 받았는데 또?」가 된다 |
| **`waitSeconds` 15초** | **유지 + 폴링 1초 → 0.2초** | 15초는 **「안 온 것으로 본다」 문턱**이라 넉넉함이 비용이 아니다. **줄일 근거가 없다 — 안 잰 조건이 셋**(셀룰러·느린 Wi-Fi·1MB 넘는 파일). 사용자가 느끼는 지연은 **폴링이 만든다** |

**정본에 올린 것 넷:**

| 자리 | 무엇 |
|---|---|
| **§2-A** | 미결 → **C 채택** · 옛 서술(「Mac에서 걸린다」)을 **「흔들린 전제」로 남겼다**(지우지 않았다) |
| **§5** | 로컬 사본의 뜻이 **「확정 때 쓴 것」 → 「받은 것도」**로 넓어졌다 · **무엇이 유지되나**를 같은 자리에 |
| **§6** | 실측 전문 + **「15초를 재려다 1초 폴링이 진짜 문제인 것을 알았다」** + 회선 조건 + 못 잰 것 넷 + 자료 확장 ② 예고 |
| **§8** | **퍼센트가 없는 것이 맞다** — 문구를 정할 때는 몰랐던 근거가 **뒤늦게** 붙었다 |

### ★ 전제 확인은 단계 5에서 함께 한다 (사용자 지시)

**「C가 그 답에 안 의존하는 것과, 그 답을 몰라도 되는 것은 다르다」**:

1. **§2는 「맥 앱은 엔타이틀먼트가 없어 스코프가 안 걸린다」고 적었는데 §2-A가 안 이어받았다** —
   **문서 안에서 어긋나 있다.**
2. **「폰에서 잠복 결함」이 사실이면 C와 별개로 알아야 할 사실이다** —
   **다른 코드에도 같은 패턴이 있을 수 있다.**
