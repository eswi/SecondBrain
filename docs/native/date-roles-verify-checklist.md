      - [x] 배지는 **D-6**(마감 `08-07` 기준 — 실기기 정상).
      ⚠️ **정정 — 원래 잡았던 "D+11(지남)" 케이스는 이제 없다.**
      어제 미루기는 미리 알림을 `08-06`으로, 마감은 `07-26`(이미 지남)이었다 → 그날 돌아오면 배지가
      **D+11(지남)** 으로 나와야 했고, 그게 **"지난 것을 미뤘는데 여유 있어 보이면 안 된다"** 의 확인이었다.
      그런데 **07-30 23:18에 폰에서 `set due=2026-08-07 resurface=2026-08-01`** 로 바뀌어
      **마감이 미래로 옮겨졌다** → 지난 마감을 미룬 상태가 아니게 됐고, 배지도 D-6(여유 있음)이 정상이다.
      → 그 불변식(지난 마감 + 미래 미리 알림 → 돌아올 때 배지는 **지남**)은 지금 실데이터에 사례가 없다.
      코드 쪽 그물은 있다: 코어 `testSplit_overdueDeadline_futureResurface_gatedOut_butDeadlineOverdue`.
      실기기로 보려면 그런 항목이 자연히 생길 때까지 기다린다(**테스트 데이터는 만들지 않는다**).
      ✅ **값 불일치 닫음 (2026-07-31, 집 맥미니 · 실데이터 재독):** 위 `07-30 23:18 set due=2026-08-07
      resurface=2026-08-01`은 **사용자가 어제 직접 고친 값**으로 확인됨 — 이상 없음(불일치 아님).
      `inbox-iphone-4532.md` 필드별 LWW(HLC 최대값) 병합 결과 **현재 값 = 마감 `2026-08-07` · 미리 알림 `2026-08-01`**
