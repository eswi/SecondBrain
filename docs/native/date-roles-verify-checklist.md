## 기록 방법

각 항목 아래 `확인:` 칸에 **날짜 · 기기 · 경로(어떤 화면에서 어떻게 했는지)** 를 적는다.
경로를 안 적으면 나중에 "어느 경로로 봤는지 모름" 상태가 된다(아래 A-3이 실제로 그렇게 됐다).
통과면 `- [ ]` → `- [x]`. 안 맞으면 고치지 말고 맨 아래 "문제 생기면 메모할 것"에 적는다.

## A. 확인 완료 (2026-07-30, 집 맥미니에서 설치 · iPhone 16 Pro)

설치 방식: `devicectl` 설치, **디버거 미부착**, 기존 서명 재사용(갱신·삭제 없음). 확인은 사용자 직접.

- [x] **A-1. 게시 게이트 — 미도래 항목이 빠지고 유실되지 않음**
      「T 우주 가입도 다시 검토」(미리 알림 미래) → **'지금 챙길 것'에서 빠지고** 살아있는 기억 쪽에 있음, **개수 보존**.
      `확인: 2026-07-30 · iPhone 16 Pro · 지금 챙길 것 → 살아있는 기억 눈 확인`
- [x] **A-2. 배지는 마감 기준**
      「우리 샌드박스 협력 병원」 배지가 **D+1 → D-1**로 바뀜(미리 알림이 아니라 마감으로 잼).
      `확인: 2026-07-30 · iPhone 16 Pro · 지금 챙길 것 목록의 배지`
- [x] **A-3. 미루기 + 규칙 1 상한**
      「이사 계획 논의」(마감 `2026-08-01`) 미루기 → **07-31로 당겨지고**(마감 하루 전에서 멈춤) 안내 표시.
      ⚠️ **어느 경로로 미룬 건지 기록이 없다** — 목록 스와이프인지 상세 화면인지 불명.
      그래서 아래 **B-3·B-4가 둘 다 남아 있다**(하나는 이미 확인된 것일 수 있음).
      `확인: 2026-07-30 · iPhone 16 Pro · 경로 미기록`
- [x] **A-4. 날짜 캡션 색**(`9598162`) — 캡션이 원문과 같은 톤으로 밝아진 것 확인.
      `확인: 2026-07-30 · iPhone 16 Pro · 지금 챙길 것 · 보관된 기억`

> 그날 보고: **12건 중 3건만 사용자 직접 확인**(위 A-1~A-3, A-4는 색 확인), 나머지는 "3건이 맞으면 같이 맞을 것으로 봄 —
> **확정 아님**". 또한 스크린샷의 엄마 생신·아이 학원·팀 회의·치과는 **시뮬레이터 SampleData**로 실데이터가 아니다.
