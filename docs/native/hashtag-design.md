# 해시태그 — 분류 안의 가벼운 세분 (2026-09-17 · 집 맥미니 · 사용자 결정)

> **성격:** 사용자가 대화에서 정한 결정을 정한 그 자리에서 적은 문서. 뜻의 정본은 `memory-philosophy.md` §7-1 해시태그 항목이고,
> 이 문서는 **저장·표시·입력**(§7-2가 미결로 남긴 셋)을 정한다. 사양서 반영은 §6에서 묻는다.

## 0. 앞서 정해져 있던 것 (여기서 안 바꾼다)

- **태그는 분류 안의 가벼운 세분 · 별개 층위**(§7-1) — 분류를 잘게 쪼개 분류 폭발을 내지 않는다.
- **첫 요구처 = 정보 안의 세분**(`classification-v2-design.md` §1-2 · 사용자: *"정보를 태그로 나누는 것은 여전히 중요한 사항이야."*).
- **그 분류에서 이미 쓰인 태그를 나열해 골라 쓰게 한다**(§7-1).

## 2. 저장 꼴 — `tag.<id>` = 태그 글

- **필드 이름 = `tag.` + 소문자 16진 32자**(`MediaPointer.newAssetId()`와 같은 id). **값 = 태그 글.**
- ⛔ **`tag.<태그글>`로 하지 않는다** — 필드 이름은 파서가 `[A-Za-z0-9_.]+`로만 읽고 소문자로 접는다(`MediaPointer` 머리주석의 제약).
  **태그 안 공백·한글·대소문자 구분**(결정 4)이 이름으로는 못 들어간다. **값**으로 들어가면 전부 무손실이다 — 공백이 있으면
  `EventWriter`가 스스로 `edit` 블록(`fields.v1` JSON)으로 보낸다(왕복 검증 경로 · 시험이 못 박는다).
- **지우기 = 빈 값**(`set tag.<id>=`) · **고치기 = 같은 id에 새 값.** 빈 값은 목록에서 걸러진다(`MediaPointer`와 같은 규칙 · `media-audit.py`의 「빈 값 = 지웠다」).
- **왜 이 꼴인가** — 병합이 항목별·필드별 LWW라 **두 기기가 각자 붙인 태그가 서로 지지 않는다**(`merge-design.md` §3 · 시험 1과 대조군 2).
- **화면 순서 = 태그 글의 정렬**(`localizedStandardCompare`). 필드에는 붙인 순서가 없다. ⚠️ 붙인 순서가 필요해지면 그때 본다.
- **다듬기(`HashTag.normalize`)**: 앞뒤 공백·줄바꿈 제거 → 앞의 `#`들을 뗀다(사람이 `#맛집`으로 쳐도 `맛집`으로 저장 · 화면이 `#`을 붙인다) →
  안의 줄바꿈은 공백으로 → 다시 앞뒤 제거 → 비면 없는 것. **안의 공백·대소문자는 그대로.** 같은 글(대소문자까지 같음)은 두 번 붙지 않는다.

## 3. 화면 — 상세 「해시태그」 절 · 목록 캡션

- **상세**에 「해시태그」 절 하나. 자리 = **분류(성역+분류 줄)와 재확인 질문 다음 · 자료 카드 앞**(분류의 세분이므로 분류 옆).
  **확정·미확정 둘 다 보인다** — 태그는 「이 기억이 무엇인가」(식별 층)의 일부라 §1-A(임시면 판단에 필요한 것만)에 맞는다고 보았다(**Claude 판단 · 사용자가 뒤집을 수 있다**).
- **칩** `#태그` 나열 + **칩의 ×로 지우기** · **칩을 누르면 그 태그를 고치는 칸이 된다** · 아래 **입력 칸**(엔터 = 붙이기).
- **그 분류에서 이미 쓴 해시태그**(§7-1)를 입력 칸 아래에 나열한다 — 살아있는 기억 전체에서 같은 분류의 태그를 모아, 이 기억에 이미 붙은 것은 뺀다. 누르면 붙는다.
- ★ **붙이기·지우기·고치기는 그 자리에서 op이다** — [저장]을 거치지 않는다(**Claude 판단** · 근거 둘: ① URL·사진 붙이기가 이미 그 길이다(`addURL`)
  ② `commitEdits`는 미확정 항목에서 `raw`·`type` 밖의 값을 **조용히 버린다**(2026-09-13의 덫) — draft로 실으면 미확정 기억의 태그가 사라진다).
  ⚠️ **그래서 「저장하지 않은 수정이 있어요」가 안 뜬다** — 되돌리려면 다시 지운다. **사용자가 다른 뜻이면 바꾼다.**
- **지우기에 되묻지 않는다**(**Claude 판단**) — 자료 삭제(사본까지 버린다)와 달리 잃는 것이 글 한 조각이고 다시 붙이면 된다.
- **목록 줄 캡션**(`itemCaption`)의 맨 뒤에 `#a #b`를 붙인다 — **있을 때만.** 캡션이 쓰이는 넷(새로운 기억·살아있는 기억·검색·보관함)에 같이 나온다(한 함수라 어긋날 자리가 없다).
- **검색은 안 바뀐다**(결정 5).

## 8. 같은 날 별건 — 「새로운 기억」 우측 가장자리 버튼 (정본은 `docs/native/edge-handle-design.md`)

같은 지시에서 *"중요한 것 하나"*로 「새로운 기억」 화면 우측에 `#`·`»` 버튼을 달았다 — **누르면 무슨 일이 생기는지는 다음 단계**(사용자).
