# 실기기 검증 체크리스트 — 되풀이(양력 반복)

> 설계 정본 = `recurrence-design.md`(§10 단계). 헤드리스로 못 보는 화면·동작만.
> 각 항목 `확인:` 칸에 날짜·기기·경로 적고 통과면 `- [ ]`→`- [x]`.
> Stage 4·5는 나중에 몰아서 — 여기 A절은 **Stage 1~3 중간 확인**(2026-08-02).

## A. Stage 1~3 (분류·설정·완료 분기)

- [ ] **A-1. 되풀이로 분류.** 새 항목 또는 기존 항목의 종류를 **되풀이**로 바꿀 수 있다. 앰버 색 + 순환 아이콘, 라벨 "되풀이".
      `확인: ____-__-__ · 기기 ______ · 경로 ______`
- [ ] **A-2. 반복 설정 카드 + 꺼두기 배너.** 되풀이 상세에 **'시간 설정' 아래** '반복 설정' 카드 — 반복 주기(매일/매주/매년)·자동 완성(없음/당일 정오/당일 지나면)·꺼두기. 저장 후 재열람 시 유지.
      **꺼두기 ON → 상세 상단에 "되풀이 꺼둠" 배너**가 바로 보인다.
      `확인: ____-__-__ · 기기 ______ · 경로 ______`
- [ ] **A-3. ★ 이번 것 했어요 → 안 사라짐.** 되풀이 상세에서 **[이번 것 했어요]** → 항목이 **살아있는 목록에서 안 사라지고** "**오늘 완료됨 ✓**"으로 바뀐다. (핵심 — status=done이 아니라 lastDone만.)
      `확인: ____-__-__ · 기기 ______ · 경로 ______`
- [ ] **A-4. 취소 → 되돌아감.** "오늘 완료됨" 옆 **[취소]** → 다시 "[이번 것 했어요]"로. (잘못 눌러도 그 자리에서 되돌림.)
      `확인: ____-__-__ · 기기 ______ · 경로 ______`
- [ ] **A-5. ★ 회귀 — 기존 항목은 여전히 보관함.** 되풀이 **아닌** 항목(할 일 등)을 완료하면 **여전히 살아있는 목록에서 빠지고 보관함(완료된 기억)으로** 간다(Stage 0 그물이 지키는 것). 스와이프 라벨은 "완료"(되풀이는 "했어요").
      `확인: ____-__-__ · 기기 ______ · 경로 ______`

## B. Stage 4 + #3 (회차·놓침·게이트 시각화) — 2026-08-03

> 실사용 "매일 약"으로 보는 게 가장 좋음. 며칠 완료를 건너뛰면 놓침이 실데이터로 뜬다.

- [ ] **B-1. #3 게이트 시각화 — 지난 시각 계속 보임 ★.** 아침 8시 미리 알림 항목을 **오후에** 열어도 '지금 챙길 것'에 **여전히 있다**(시각 지났다고 안 빠짐).
      `확인: ____-__-__ · 기기 ______ · 경로 ______`
- [ ] **B-2. #3 — 미래 시각은 그 시각부터.** 미리 알림이 **오늘 늦은 시각**(예: 20시)인 항목은 낮엔 '지금 챙길 것'에 **없다가 그 시각에 나타난다**. (date-only 항목은 지금처럼 자정부터.)
      `확인: ____-__-__ · 기기 ______ · 경로 ______`
- [ ] **B-3. 완료 → 즉시 다음 회차로 넘어감 ★.** 되풀이 "이번 것 했어요"(또는 스와이프 "했어요") → **'지금 챙길 것'에서 바로 빠진다**(다음 회차는 미래라 게이트가 숨김). 화면이 그대로면 안 됨.
      `확인: ____-__-__ · 기기 ______ · 경로 ______`
- [ ] **B-4. 다음 회차 도래 시 다시 나타남.** 다음 날(또는 다음 주기) 그 시각이 되면 다시 '지금 챙길 것'에 나타난다.
      `확인: ____-__-__ · 기기 ______ · 경로 ______`
- [ ] **B-5. 놓침 = 계속 보이고 "N일 놓침" ★.** 며칠 완료를 건너뛰면 항목이 **계속 '지금 챙길 것'에 남고**(쌓임), 상세 상단 배너·목록 칩에 **"N일 놓침"**이 뜬다. (자동 완성 "없음"인 약에서.)
      `확인: ____-__-__ · 기기 ______ · 경로 ______`
- [ ] **B-6. 자동 완성.** 자동 완성 "당일 지나면"/"당일 정오"로 둔 되풀이는 그 시점이 지나면(앱 열 때) **저절로 다음 회차로 넘어가 안 쌓인다**(습관·생일 케이스).
      `확인: ____-__-__ · 기기 ______ · 경로 ______`
- [ ] **B-7. #4 — 목록에서 오늘 완료가 보인다.** 완료한 되풀이가 '살아있는 기억'으로 가면 **"오늘 완료" 칩**이 목록에 보인다(상세 안 열어도).
      `확인: ____-__-__ · 기기 ______ · 경로 ______`

## C. 앵커 전환 (마감=회차 시각, 미리 알림=게시 시작/lead) — 2026-08-03

> **모델 정정:** 마감 = 회차 앵커(회차 시각), 미리 알림 = 게시 시작(lead). 완료 시 둘 다 같은 간격 전진(lead 보존).
> 마감만 있어도 **마감 시각부터** 보임(게이트 시각 인지). B절의 "앵커=미리 알림" 서술은 이 C절로 대체.

- [ ] **C-1. 두 칸 다 보인다.** 되풀이 상세 "시간 설정"에 **"회차 시각"(마감) + "미리 알림"** 두 칸이 있다(일반 항목과 동일).
      `확인: ____-__-__ · 기기 ______ · 경로 ______`
- [ ] **C-2. ★ 옛 되풀이 3개(마감만·lead 0)가 실제로 돈다.** E036A094·90D927B2·01781308(전부 마감에 시각, 미리 알림 없음):
      **마감 시각부터 '지금 챙길 것'에 보이고** → "이번 것 했어요" → **마감만 다음날로 전진(미리 알림은 계속 비어 있음)** → 즉시 빠짐. (헤드리스로 고정: `testCompletionAdvance_noResurface_onlyDueAdvances`.)
      `확인: ____-__-__ · 기기 ______ · 경로 ______`
- [ ] **C-3. ★ lead 보존 — 8시 마감 + 7시 미리 알림.** 새 되풀이를 마감=오늘 08:00, 미리 알림=오늘 07:00으로 →
      **7시부터 보이고**, 완료하면 **마감 08-04·미리 알림 08-04 둘 다 다음날로**(lead 1시간 유지) → 빠짐.
      `확인: ____-__-__ · 기기 ______ · 경로 ______`
- [ ] **C-4. 규칙 1(시각).** 미리 알림을 마감보다 **늦은 시각**으로 잡으려 하면 막힌다. **미리 알림 = 마감(정각)은 허용**(실질 lead 0). date-only 미리 알림은 여전히 하루 전.
      `확인: ____-__-__ · 기기 ______ · 경로 ______`

> **⚠️ 알림 주의(Stage 5 미구현):** 7시 미리 알림 + 8시 마감 약은 지금 **7시에만 알림, 8시엔 안 옴**(§3-A lead-time 구멍). C절 화면·회차 확인엔 영향 없음 — 알림 시각만 그렇다는 것 인지.
> **01781308(마감 00:10) = 경계 시험용(자정 근처).** 날짜 경계에 걸려 헷갈릴 수 있음 — 확인용으로만 두고, 정리해도 무방(그만두기=삭제, 값은 안 지워짐).

> 옛 `doneToday`(날짜 기준)가 게이트(시각 기준)와 갈려 낸 "완료+지남 동시" 모순을 없앴다.
> **폰에 09:13 빌드 설치됨**(`kr.teri.secondbrain`). 헤드리스: Core 167 통과 + iOS 빌드 OK.

- [x] **D-1. ★ 옛 모순 항목(`복약: 놓치는 약 먹기`) 해소.** 지금은 마감 06:00(과거)+lastDone 00:11이라 **"지남"만** 뜨고 **"오늘 완료" 칩은 안 뜬다**(모순 사라짐). → **"이번 것 했어요" 눌러** 완료 → **마감 내일 06:00로 전진** → '지금 챙길 것'에서 빠져 **'살아있는 기억'으로** 가고, 거기서 **"완료" 칩**이 뜬다. (신 빌드 재완료가 실제로 전진하는지도 이걸로 같이 확정.)
      `확인: 2026-08-04 · iPhone 16 Pro · 새로운 기억 탭 '지금 챙길 것' → 복약 상세 "이번 것 했어요" → 살아있는 기억 탭 "완료" 칩` — **통과. "오늘 완료+지남 동시" 모순 사라짐 확인.**
- [x] **D-2. 상세 배너 문구.** 완료 후 상세에서 **"이번 회차 완료됨 ✓" + [취소]**. (옛 "오늘 완료됨"에서 바뀜 — 매주·매년도 맞게.) [취소] 누르면 되돌아가 다시 "이번 것 했어요".

## E. 꺼두기가 실제로 멈추는지 — 2026-08-03

> **고친 것:** 상세 배너가 "되풀이 꺼둠 — 알림·되살아나기 멈춤"이라고 약속하는데 `isPaused`를 읽는 곳이
> DetailView(토글·배너)뿐이라 **셋 다 안 지켜졌다.** 새 기능이 아니라 **이미 있던 거짓 약속**을 고쳤다.
> 네 곳: 알림(`plan`)·게시(`isPublished`)·자동완성 catch-up(`catchUpChanges`)·**놓침 계산**(`missed`).
> 헤드리스: Core **179 통과** + iOS 빌드 OK. **폰에 2026-08-03 18:40 빌드 설치됨**(`kr.teri.secondbrain`, iPhone 16 Pro).
>
> **핵심 실패 양상 = 항목이 사라지는 것.** 꺼두기는 항목을 숨기는 게 아니라 **'지금 챙길 것'에서만 빼는 것**이고,
> 항목 자체는 시점 없는 쪽으로 옮겨가 총 개수가 보존돼야 한다(§7(c)). A-3과 같은 등급으로 볼 것.
>
> **⚠️ 이 절 최초 작성 때 화면 이름을 틀렸다(2026-08-03 실기기 확인에서 드러남).** "최근 들어온 것"이라는 섹션은
> **없다.** Core의 `recent`(시점 없음)를 App이 **확정 여부로 다시 쪼갠다**(`InboxModel.partition`):
> **확정 → '살아있는 기억' 탭 / 미확정 → '새 기억들' 섹션.** 꺼둔 항목이 어디로 갈지는 그 항목의 확정 여부가 정한다.
> Core 주석 3곳의 옛 이름도 같이 정정했다(같은 종류의 "화면에 없는 말" 문제).
>
> **놓침 숫자를 보는 곳 세 군데:** '지금 챙길 것' 카드 칩(`UpcomingCard`) · '새 기억들'/'살아있는 기억' 한 줄 칩
> (`MemoryRow` — 꺼둔 항목은 여기서 보인다) · **상세 상단 배너**(꺼둠 배너 바로 아래, 항상 보임).

- [x] **E-1. ★ 꺼두면 목록에서 빠지되 사라지지 않는다.** 되풀이 항목(예: `복약`) 상세 → "반복 설정" 카드의 **꺼두기 스위치 ON** → 저장. **'지금 챙길 것'에서 빠지는지** 확인 → **확정 항목이면 '살아있는 기억' 탭, 미확정이면 '새 기억들' 섹션에 있는지** 확인. **어느 쪽에도 없으면 즉시 실패로 적을 것.**

      `확인: 2026-08-03 · iPhone 16 Pro · 꺼둔 항목 상세 상단` — **통과. 붉은 배너 확인.**

- [ ] **E-5. 다시 켜면 복귀한다.** 꺼두기 스위치 **OFF** → 저장 → 배너 사라짐 + **'지금 챙길 것'으로 복귀**(회차 시각이 지난 상태면). 자동 완성이 있으면 밀린 회차가 **한 번에 전진**해 다음 회차로 맞춰진다.
      `확인: (미확인) **E-3 확인 후 진행 예정** · iPhone 16 Pro · 경로 ______`
- [ ] **E-6. ★ 놓침이 꺼둔 기간만큼 붙지 않는다.**
      **⚠️ E-3 대상 항목으로는 확인 불가 — 자동 완성 '당일 지나면'이면 놓침이 절대 안 쌓인다**(catch-up이 매일 회차를 넘겨 항상 0). 자동 완성 = **없음**인 **별도 항목**이 필요하다. 이게 자동완성의 뜻 그대로라 버그가 아니다.
      **준비(기다릴 필요 없음):** 되풀이 항목을 하나 새로 만들고 주기=**매일**, 자동 완성=**없음**, **회차 시각(마감)을 며칠 전 날짜**로 넣는다 → 그 즉시 **"N일 놓침"**(N = 지난 회차 수)이 뜬다. 며칠 기다려 쌓을 필요가 없다.
      **절차:** ① 위처럼 만들어 칩 숫자 N을 적어 둔다 → ② 꺼두기 ON, 숫자가 그대로 N인지 확인 → ③ **하루 넘긴 뒤** 다시 보아 **여전히 N**이면 통과(N+1이면 실패 — 고치기 전 동작) → ④ 켜고 나서도 **여전히 N**인지 확인(경계에서 안 튀는지).
      `확인: (미확인) 날짜 ______ · 기기 ______ · 경로 ______`
      **뜻:** 꺼둔 것은 "세지 않겠다"는 뜻이다. 꺼두기 전 놓침은 **보존**하고(사면이 아니다) 꺼둔 구간만 건너뛴다.
      **주의 1:** "이번 것 했어요"를 누르면 회차가 전진해 놓침이 사라진다 — E-6 동안 **누르지 말 것**.
      **주의 2:** 이 빌드 **이전에 이미 꺼둬 둔** 항목은 꺼둔 시점 기록(`recurPausedAt`)이 없어 옛 동작(계속 셈)으로 폴백한다 — 그건 실패가 아니다. **이 빌드에서 새로 껐다 켠 것**으로 확인할 것.

## 실사용 데이터 만들기 (권장)
- **"매일 아침 약 먹기"** 되풀이 항목을 실제로 하나 만들어 둔다: 종류=되풀이, 주기=**매일**, 미리 알림=오늘+아침 시각, 자동 완성=**없음**(약은 쌓여야 놓침이 생김).
- Stage 4(놓침 계산) 전에 만들어도 **안전** — 필드는 안정 인코딩(recur/recurAuto/recurPaused/lastDone)이고 LWW 자동 병합. Stage 4는 그 위에 계산만 얹는다.
- **놓침 데이터를 만들려면 며칠은 완료를 건너뛴다**(매일 누르면 놓침=0). lastDone(마지막 완료) + 경과가 Stage 4의 입력.
