# 해시태그 필터 — 가장자리 손잡이를 누르면 나오는 것 (2026-09-22 · 사용자 결정)

> **정본.** 손잡이의 꼴·움직임은 `edge-handle-design.md`, 해시태그의 저장·상세 UI는 `hashtag-design.md`.
> 이 문서는 **「손잡이를 누르면 무엇이 나오나」**(그 문서 §4의 미결)에 대한 답이다.

## 1. 지시 — 사용자 말 그대로 (2026-09-22 01:1x KST · 집 맥미니)

> *"그 버튼의 역할은 해시태그 필터를 위한 것이야. 기억의 목록들이 나오는 모든 창 '새로운 기억', '검색', '살아있는 기억', '보관된 기억' 에서
> 현재 화면에 나열된 기억들의 모든 해시태크를 나열하고 그 중 선택된 해시태그를 가진 기억만 화면에 보이게 하는 기능이야.
> 해시태크는 중복 선택 가능하고 해시태그의 마지막에는 '태그 없음'도 있어야 해. 즉, 태그 없는 기억 혹은 태그 있는 기억도 선택될 수 있도록.
> 선택 가능한 해시태그 아랫단에는 수평 seperator를 하나 긋고 그 아래에 '역선택' 토글 버튼도 하나 둬서, 그걸 켜면 현재 해시태그 필터링으로
> 선택된 기억들을 숨기고 반대로 선택되지 않은 기억들을 보이게 해줘. 그리고 '역선택' 버튼 우측에는 '닫기 >' 버튼을 둬서 그 버튼을 누르면
> 선택 화면이 감춰지도록 해줘. 개발하자!"*

## 3. 구조

- **Core `TagFilter`**(`SecondBrainCore/TagFilter.swift`): `selected: Set<String>` · `includesUntagged`(=「태그 없음」) · `inverted`(=「역선택」).
  `matches(tags)` = 활성이 아니면 전부 참 · 활성이면 `(선택 ∩ 태그 ≠ ∅) ∨ (태그없음 ∧ 태그 = ∅)` · 역선택이면 그 부정.
  `available(items)` = 필터 전 목록의 태그(중복 제거 · 정렬). `pruned(to:)` = 화면에 없는 태그를 선택에서 접는다.
  **결정 파수꾼 = `TagFilterTests`**(OR · 태그 없음 · 역선택은 정확히 여집합 · 비활성 = 전부 · 접기).
- **앱 `TagFilterDock`**(`Sources/App/TagFilterPanel.swift`): 손잡이(`EdgeHandle` + `onTap`) 또는 패널(`TagFilterPanel`) 중 하나를 그 자리에 그린다. 네 화면이 각자 `@State var tagFilter`·`showTagPanel`을 가지고 이것을 목록 영역에 얹는다.
- `EdgeHandle`은 **`onTap`과 `active`(필터 걸림 표시)** 둘만 늘었다 — 꼴·움직임은 09-21 그대로.
