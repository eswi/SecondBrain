## 3. 구조

- **Core `TagFilter`**(`SecondBrainCore/TagFilter.swift`): `selected: Set<String>` · `includesUntagged`(=「태그 없음」) · `invert(available:)`(=「역선택」 동작 · 선택을 여집합으로 · 「태그 없음」 뒤집기). *(옛 · 19:5x까지 `inverted` 플래그 — 걷었다 · §7-5)*
  `matches(tags)` = 활성이 아니면 전부 참 · 활성이면 `(선택 ∩ 태그 ≠ ∅) ∨ (태그없음 ∧ 태그 = ∅)`.
  `available(items)` = 필터 전 목록의 태그(중복 제거 · 정렬). `pruned(to:)` = 화면에 없는 태그를 선택에서 접는다.
  **결정 파수꾼 = `TagFilterTests`**(OR · 태그 없음 · 역선택 = 선택 뒤집기·두 번이면 원래대로 · 비활성 = 전부 · 접기 · 숫자 셋). *(옛 3 · 「역선택은 정확히 여집합」 — 뒤집혔다)*
- **앱 `TagFilterDock`**(`Sources/App/TagFilterPanel.swift`): 손잡이(`EdgeHandle` + `onTap`) 또는 패널(`TagFilterPanel`) 중 하나를 그 자리에 그린다. 네 화면이 각자 `@State var tagFilter`·`showTagPanel`을 가지고 이것을 목록 영역에 얹는다.
- `EdgeHandle`은 **`onTap`과 `active`(필터 걸림 표시)** 둘만 늘었다 — 꼴·움직임은 09-21 그대로.

### 7-5. 「역선택」은 스위치가 아니라 **선택을 뒤집는 동작** (2026-09-22 20:2x 사용자 · `874fd62` · 20:31 폰 설치 · ⏸ 대기)

**사용자:** *"역선택에 시스템 스위치를 쓴 것은 좋은 결정이 아니었다. 화살표 두개가 서로 꼬리를 물며 원모양으로 그려지는 아이콘을 하나 달고, 역선택 버튼을 바탕색없이 글자로만 표시하는 방식으로 하자. 켜고 끄는 것이 아니라, 결정된 태그들이 반대로 뒤바뀌는 변화를 한 번에 주는 방식으로 하자. 토글이 맞고, 그냥 바로 선택을 역전시키는 방식."*

- **꼴:** `arrow.2.circlepath`(14pt에서 17×16 · 심볼 선택은 Claude — 사용자는 꼴을 말했다) + 「역선택」 14pt semibold · 바탕 없음 · 「닫기 >」와 같은 버튼 꼴. 폭 17 + 4 + 36.4 + 여백 12 ≈ **69**(스위치 때 93) — 아래 띠가 다시 제목 띠와 같은 높이.
- **동작:** `TagFilter.invert(available:)` — `selected = available − selected` · `includesUntagged.toggle()`. 화면에 없는 태그는 이때 버린다(`pruned`와 같은 이유). **`inverted` 플래그는 걷었다**(Core·시험·패널 전부 — 다른 자리에서 안 쓰고 있었다 · `grep`으로 확인).
- ⚠️ **뜻이 달라진 자리 하나 — 여집합이 아니다.** 옛 플래그는 **보이는 목록의 정확한 여집합**이었다(옛 시험 3). 새 방식은 **태그 집합을 뒤집는 것**이라 OR 판정에서 **태그를 여럿 가진 기억은 뒤집기 전후에 둘 다 보일 수 있다**
  (「맛집·서울」 기억: 「맛집」을 골라도 걸리고, 뒤집어 「서울」이 골라져도 걸린다 · 시험 3 주석). **사용자 지시 그대로 만들었고 이 차이는 알려 드린다** — 여집합이 필요하면 옛 방식(플래그)으로 돌아가야 하고, 그러면 칩이 뒤집혀 보이지 않는다(둘을 동시에 가질 수 없다).
- **제목 숫자 셋은 이제 역선택을 따라간다**(선택이 바뀌므로) — 옛 「역선택과 무관」 조항(§7-3 · 시험 7)은 플래그 시절의 말이라 시험 7을 다시 썼다(합이 맞고 · 고른 것이 없으면 선택 0).
- **아무것도 안 고른 채 누르면** 전부(+「태그 없음」) 고른 것이 된다 — 칩이 다 켜지고 목록은 전부 보인다(`isActive`이지만 걸리는 것이 전부). 한 번 더 누르면 다 꺼진다.
- **시뮬(26.5 · 임시 빌드 · 되돌렸다 · 본 뒤 적는다):** 아이콘 + 「역선택」 + 「닫기 >」 한 줄 · 제목 14pt 한 줄. 누르는 동작은 시뮬에서 안 눌렀다(항시 규칙 7).

**판정 — 폰에서 볼 것(`874fd62`):** ⓕ′ 아래 띠에 원 화살표 아이콘 + 「역선택」(바탕 없음) · 누르면 **고른 칩이 꺼지고 안 고른 칩이 켜지며 「태그 없음」도 뒤집힌다** · 목록·제목 숫자가 따라 바뀐다 · 두 번 누르면 원래대로 · ⓖ 제목 글자 = 「닫기」 크기 · 한 줄 · ⓗ 「닫기 >」 한 줄.
