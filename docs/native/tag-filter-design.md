## 3. 구조

- **Core `TagFilter`**(`SecondBrainCore/TagFilter.swift`): `selected: Set<String>` · `includesUntagged`(=「태그 없음」) · `inverted`(=「역선택」).
  `matches(tags)` = 활성이 아니면 전부 참 · 활성이면 `(선택 ∩ 태그 ≠ ∅) ∨ (태그없음 ∧ 태그 = ∅)` · 역선택이면 그 부정.
  `available(items)` = 필터 전 목록의 태그(중복 제거 · 정렬). `pruned(to:)` = 화면에 없는 태그를 선택에서 접는다.
  **결정 파수꾼 = `TagFilterTests`**(OR · 태그 없음 · 역선택은 정확히 여집합 · 비활성 = 전부 · 접기).
- **앱 `TagFilterDock`**(`Sources/App/TagFilterPanel.swift`): 손잡이(`EdgeHandle` + `onTap`) 또는 패널(`TagFilterPanel`) 중 하나를 그 자리에 그린다. 네 화면이 각자 `@State var tagFilter`·`showTagPanel`을 가지고 이것을 목록 영역에 얹는다.
- `EdgeHandle`은 **`onTap`과 `active`(필터 걸림 표시)** 둘만 늘었다 — 꼴·움직임은 09-21 그대로.

### 7-1. 계산 — 폭과 칩 여백 (macOS 메트릭 `measure-text.swift` · 화면 402pt · 계측 규칙 7: 계산이고 화면에서 닫았다)

**글자 폭(14pt):** `#` 8.7 · 한글 한 자 12.2 · 「태그 없음」 52.3. 칩 폭 = 2×좌우여백 + 8.7 + 12.2×글자수 · 칩 사이 간격 · 패널 안쪽 여백 양쪽.

| 폭 | % | 칩 여백 9 · 사이 6 · 안쪽 12(옛) — 2자·3자·4자·5자 태그가 한 줄에 | 칩 여백 7 · 사이 4 · 안쪽 10(새) |
|---|---|---|---|
| 173 | 43 | 2개·2개·1개·1개 | **3개**·2개·**2개**·1개 |
| 177 | 44 | 2·2·1·1 | 3·2·2·1 |
| **181** | **45** | 2·2·**2**(문턱 정확히 181.0 — 아슬) ·1 | 3·2·2·1 |
| 185 | 46 | 2·2·2·1 | 3·2·2·1 |
| 189 | 47 | 2·2·2·1 | 3·2·2·1 |

- **결론: 폭을 1~2% 움직여도 글자 수는 안 변한다** — 43~47% 안에서 옛 여백은 한 번(4자 2개, 45.0%)만 바뀌고 새 여백은 **평평하다.** 변하는 것은 **칩 여백**이다: 2자 태그(실데이터 꼴 — 지금 태그 셋 `업무`·`제품`·`맛집`이 다 2자) 한 줄 **2개 → 3개**, 4자 태그 **1개 → 2개.**
  다음 문턱(2자 4개 · 3자 3개)은 **51~55%**라 범위 밖. → **45% + 여백 7/4/10**으로 정했다. 폭이 문턱 위에 얹혀 있지 않아 기기 폭·글꼴 차이에 덜 흔들린다.
- **제목 폭(13pt):** 「전체 123 · 선택 45 · 그 외 78」 = **157.1pt** ≤ 안쪽 폭 161(181 − 10×2). 세 자리 셋이면 넘칠 수 있어 `minimumScaleFactor(0.8)`로 한 줄 안에서 줄인다. 지금 살아있는 기억 94개(`inbox-state.py` · 09-22 맥북)라 두 자리다.
  후보 넷을 폭과 함께 보였고 **사용자가 「전체 N · 선택 N · 그 외 N」을 골랐다**(다른 후보: 「전체·선택·나머지」 164.8 — 13pt 넘침 · 「N · 선택 N · 나머지 N」 138.7 · 「N = N + N」 84.0).
- ⚠️ **표본이 좁다** — 실데이터 태그가 셋(전부 2자)뿐이라 3~5자 열은 **가정**이다. 계산식은 글자 수에 선형이므로 실데이터가 자라도 문턱 계산은 그대로 쓸 수 있다.

### 7-2. 판정 — 폰에서 볼 것 (`afde395` · 14:24 설치 · ⏸ 대기)

ⓐ 패널이 **세 영역**으로 보인다 — 위 제목 띠와 아래 띠가 같은 밝은 바탕, 가운데 칩 영역이 그보다 어둡다(그래도 옛것보다 밝다) ·
ⓑ 패널 폭이 화면의 **절반보다 조금 좁다**(45%) ·
ⓒ **안 고른 칩에도 회색 바탕**이 있고, 고른 칩은 전처럼 강조색이다 · 「태그 없음」은 회색 바탕에 흐린 글자 ·
ⓓ 제목 **「전체 N · 선택 N · 그 외 N」** — 아무것도 안 골랐을 때 「선택 0 · 그 외 = 전체」 · 고르면 선택 + 그 외 = 전체 · **「역선택」을 켜도 셋이 안 바뀐다**(보이는 목록만 뒤집힌다 · Claude 판단 — 뒤집을 수 있다) ·
ⓔ 「살아있는 기억」에서 2자 태그가 **한 줄에 3개** 들어간다(옛 2개).

### 7-3. 이번에 Claude가 판단한 자리 (사용자가 뒤집을 수 있다)
- **숫자 셋은 「역선택」과 무관하다** — 「선택된 기억」 = 고른 태그에 걸린 기억. 역선택은 무엇을 보이나만 뒤집는다(`TagFilter.counts` · 파수꾼 시험 7).
  다르게(「보이는 것 · 숨은 것」으로) 하려면 한 줄이다 — 그러면 문구도 다시 골라야 한다.
- 고른 것이 없으면 「선택 0 · 그 외 N」(전부 보이지만 「선택」은 0).
- 색값 셋과 여백 셋(7-1)은 Claude 값이다.
