# 아이폰 실기기 검증 체크리스트 — 알림 실배선 (네이티브 v1, Phase 3 배달)

> 목적: 미루기·마감(resurface/due) 날짜에 **실제 로컬 알림이 뜨는지** 실기기로 확인한다.
> 로직(언제·무엇을)은 `NotificationPlanner`로 이미 테스트됨(36개). 여기서는 **실제 발화**만 확인.
> 로컬 알림은 iOS·macOS 모두 **entitlement 불필요 = 무료 서명 유지**.
> 앞선 iCloud 배선 검증은 `iphone-verify-checklist.md`에서 완료됨.

## 동작 방식 (알아둘 것)
- 알림 시각 = 항목의 **resurface(미루기) 날짜** 우선, 없으면 **due(마감) 날짜**. 그 날 **오전 9시**.
- **미래만** 등록(과거 시점은 앱 안 "곧 닥칠 것"이 담당). 이른 순 최대 32개(iOS 64 제한 대비).
- 앱이 모든 로컬 알림을 소유 → 로드/행동마다 **전부 지우고 다시 등록(멱등)**. 삭제·완료하면 그 알림도 사라짐.

## A. 권한 허용
1. 앱을 아이폰에서 실행(⌘R). 폴더 이미 선택돼 있으면 첫 로드 시
2. **"'SecondBrain'에서 알림을 보내려고 합니다"** 시스템 팝업 → **허용** 탭.
   - [ ] 팝업이 떴고 허용함. (안 떴으면 설정 > 알림 > SecondBrain에서 켜기)

## B. 알림이 실제 등록되는지 (빠른 확인)
가장 빠른 검증 = **오늘 날짜로 미루기**가 아니라, **가까운 미래**로 확인.
- [ ] 아무 항목 미루기(→ 7일 뒤 resurface). 캡션에 `↻<날짜>` 확인.
- [ ] (개발용 빠른 확인) 발화 시각은 그 날 **오전 9시**라 바로는 안 뜬다. 즉시 확인하려면:
      아이폰 **설정 > 일반 > 날짜 및 시간**에서 자동 끄고, 시계를 **그 날 오전 8:59**로 맞춘 뒤 1분 대기 →
      **9:00에 배너가 뜨는지** 확인. (확인 후 자동으로 되돌리기.)
  - [ ] 예정 시각에 **"받은함 · 곧 닥칠 것"** 제목 + 항목 내용 배너가 떴다.

## C. 멱등·정리 확인
- [ ] 알림이 등록된 항목을 **삭제** → 그 항목 알림도 더는 안 뜬다(다음 로드에 정리됨).
- [ ] 같은 항목을 여러 번 미루기해도 알림이 **중복 등록되지 않는다**(id 기준 하나만).

## D. macOS도 (선택)
- [ ] Mac 앱 실행 → 알림 권한 허용 → 같은 방식으로 알림 뜨는지. (macOS 알림 센터)

## E. 이번 범위 / 알아둘 것
- 알림 **탭 동작**은 기본(앱 열기)만. 특정 항목으로 점프 등은 이번 범위 밖.
- 앱이 **포그라운드**일 때는 기본적으로 배너가 안 뜰 수 있음(iOS 기본 동작). 실사용(9시, 앱 꺼짐)에선 정상 표시.
- 서명 만료 → **유료 등록이라 ~1년**(재설치 말고 Xcode ⌘R로 재서명 갱신). 상세·앱 삭제 금지 = `iphone-verify-checklist.md` F·G.

## 문제 생기면 메모할 것
- 권한 팝업이 안 뜸 / 허용했는데 발화 안 됨 → 어느 단계인지.
- 삭제했는데 알림이 남음 / 중복으로 뜸.
- macOS에서만/iOS에서만 되는지.
→ 이 내용 알려주면 바로 조치.
